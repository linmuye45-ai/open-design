# 锦鲤棋牌 · 正宗中式棋牌（原型）

面向 35–65 岁人群的正宗中式棋牌游戏原型。**第一阶段已实现完整可玩的斗地主**，
掼蛋、麻将作为后续模块扩展。

## 在线体验
本地启动：
```bash
cd qipai-prototype
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
手机端可直接用浏览器访问（已做移动端竖屏适配）。

## 已实现功能
| 模块 | 说明 |
|---|---|
| 规则引擎 `js/rules.js` | 完整斗地主牌型识别（单/对/三带/顺子/连对/飞机/四带/炸弹/王炸）+ 合法比较；24 项单元测试全过 |
| AI 引擎 `js/ai.js` | 候选牌型枚举 + 4 档难度（新手/普通/高手/大师），含拆炸、留大牌、配合队友、残局拦截逻辑；200 局自动对局无非法出牌 |
| 主控 `js/game.js` | 状态机、叫地主、回合调度、计时、结算、段位/金币持久化 |
| 音频 `js/audio.js` | Web Audio 程序化生成中式五声音阶 BGM（随牌局紧张度动态变化）+ 出牌/炸弹/王炸/胜负音效，无外部音频文件 |
| UI/UE `css/style.css` | 适老化设计：黑体大字号、高对比、图标配文字；扇形手牌**全程完整可见**；炸弹/王炸惊艳特效 + 胜利彩带 |
| 美术 `assets/` | 原创高清牌桌背景、中式牌背、角色头像 |

## 针对调研痛点的设计决策
- **无强制广告 / 无诱导充值弹窗**（竞品最大差评点）
- **公平可信**：AI 难度透明可调，杜绝“暗改胜率”观感
- **适老化**：大字号、高对比、出牌区放大、牌面任何时候完整显示
- **吸引付费的正向设计**：排位段位（青铜→王者）、倍数翻炸、金币成长，靠成就感而非套路

## 可调设置
- AI 难度：新手 / 普通 / 高手 / 大师
- 出牌速度：慢 / 中 / 快 / 极速
- 音效 / 背景音乐 独立开关
