# 🐟 锦鲤牌阵 Koi Fortune

> 国风扑克 · 构筑肉鸽 · 牌型解谜爆分
> An original Chinese-styled poker-building roguelite. **Strategy deck-building, NOT gambling.**

从一手牌中组出「牌阵」，用 **符箓（宝物）** 不断叠加 **底分 × 倍率**，在爆分中冲破每一关的目标分。12 关、4 场「局势」考验、3 大门派、33 种符箓——条条构筑，皆可龙门一跃。

**本作是策略构筑 / 牌型解谜 / 国风肉鸽游戏。全程无真钱、无金币输赢、无提现、无红包、无房卡、无抽卡、无广告。**

## 🎮 玩法（10–15 分钟一局）

1. **选门派** —— 财神堂 / 文曲阁 / 江湖派，各带不同开局符箓与构筑风格。
2. **组牌阵** —— 从 8 张手牌里选 1–5 张，系统识别牌型：
   孤星(高牌) · 成双(对子) · 鸳鸯(两对) · 三合(三条) · 长龙(顺子) · 同象(同花) · 满堂(葫芦) · 四方(四条) · 游龙(同花顺) · 五福(五条)。
3. **爆分公式** —— `得分 = round(底分 chips × 倍率 mult)`。符箓在计分的各个阶段介入，持续堆叠两者。
4. **过关得铜钱** —— 在「符箓铺」采买符箓、镀金牌、精简牌库，构筑你的爆分流派。
5. **局势(Boss)** —— 第 3 / 6 / 9 / 12 关有限制（锁门判官减手牌、克扣御史打八折、夺钱阎罗先扣分、逆袭真君抬目标），考验构筑韧性。
6. **每关有限次数** —— 出牌 4 次、弃牌 3 次；用尽仍不达标即失败。冲破 12 关即通关。

> 「铜钱」只是**局内一次性构筑资源**，不能充值、不能提现、不能兑换任何财物，游戏结束即清空。

## 🎨 视觉与交互

- **国风质感**：墨绿牌桌、金线勾边、宣纸底纹、漆器高光。
- **适老化**：大字号（基准 18px）、大按钮（≥44px 触控区）、高对比、低误触；**手牌中每张牌的点数与花色永不被遮挡**。
- **爆分反馈**：`底分 × 倍率 → +总分` 飞字，随分档升级（財字落印 / 金鲤跃动），适合短视频传播。
- **动态音效**：随局势 平局→连击→Boss→爆分 变化，一键静音。
