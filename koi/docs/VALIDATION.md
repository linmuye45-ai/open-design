# 📊 三个月 Demo 验证计划 (VALIDATION)

> 目的：用**最低成本**验证「中式牌型 + 构筑肉鸽」是否成立，再决定是否投入完整版。
> 本文所有数字均为**目标假设**，非已实现结果。

---

## 验收标准（当前原型已满足项 ✅）

- ✅ `npm install && npm run dev` 可运行。
- ✅ `npm test` 通过核心规则测试（44 用例：牌型识别 / 符箓计分 / 肉鸽流程 / 存档成就）。
- ✅ 玩家可走通完整循环：开始 → 选门派 → 出牌结算 → 得符箓 → 下一关 → 失败/通关。
- ✅ 至少 3 个可录制的 15 秒短视频点（爆分 / Boss 逆转 / 构筑成型）。
- ✅ 全程无真钱 / 提现 / 赌博 / 金币输赢机制或文案。
- ✅ 不宣称任何未经证实之事（百万并发 / 已上架 / 版号 / 融资）。

---

## 验证渠道与假设指标

| 渠道 | 动作 | 观察指标（目标假设） |
|---|---|---|
| **Steam** | 上线免费 Demo + 愿望单页 | Demo→愿望单转化、Demo 平均时长 ≥ 15min |
| **B站** | 发布 3 条爆分/构筑切片 | 完播率、评论中的「想玩」意向 |
| **抖音 / TikTok** | 竖屏爆分名场面 | 转发率、点赞收藏比 |
| **Reddit** | r/roguelites、r/balatro 发试玩 | 正向讨论、bug/平衡反馈质量 |
| **Discord** | 建测试社群 | 次日/7 日回访、构筑分享数 |

## 关键验证问题

1. **上手性**：不懂扑克的玩家能否在 2 分钟内完成第一次出牌？
2. **深度感知**：玩家能否自发讨论「流派/构筑」，而非只讨论运气？
3. **爆分爽感**：爆分动画是否被主动录屏/分享？
4. **合规认知**：玩家/平台是否清楚这是策略游戏而非赌博？（对外表述统一为策略牌局/构筑/牌型解谜/国风肉鸽）
5. **付费意愿**：在**确定性内容**前提下，玩家是否愿意为 DLC 主题包付费？

## 数据埋点（本地、匿名、可关闭）

原型仅本地记录：最远关卡、单次最高爆分、通关次数、见过的符箓数（见 `src/game/save.ts`）。
正式版如接入分析，将匿名化并提供关闭选项，不采集敏感信息。

## 决策门（Go / No-Go）

- **Go（投入完整版）**：Demo 时长与愿望单转化达到内部目标假设，且社区出现自发构筑讨论与短视频传播。
- **Iterate（迭代）**：爽感达标但深度不足 → 扩符箓与门派；深度达标但上手差 → 强化引导与牌型速查。
- **No-Go（暂停）**：核心爽点无法被短视频验证，或合规表述无法被平台接受。

## 30 天迭代计划（示例）

- **第 1 周**：美术第一版（牌面/桌面/符箓图标）+ 平衡首轮打磨。
