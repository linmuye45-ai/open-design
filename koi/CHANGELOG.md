# 更新日志 Changelog

本项目遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.1.0] - 2026-07-06

### 首个可运行原型 (MVP)

- **核心循环**：选门派 → 组牌阵 → 底分×倍率爆分 → 过关得铜钱 → 符箓铺构筑 → 下一关（含局势 Boss）→ 通关/失败。
- **牌型系统**：10 种原创国风牌型（孤星/成双/鸳鸯/三合/长龙/同象/满堂/四方/游龙/五福）。
- **符箓系统**：33 种符箓，覆盖财神/文运/江湖三系 + 通用增强，含完整计分流水线。
- **门派**：财神堂 / 文曲阁 / 江湖派，各带不同开局符箓与风格。
- **关卡**：12 关目标分曲线，4 场局势 Boss（锁门判官/克扣御史/夺钱阎罗/逆袭真君）。
- **UI**：国风视觉、适老化大字号高对比、牌面永不遮挡、爆分动画、动态音效 + 一键静音。
- **存档**：本地 localStorage 存档 + 8 项成就（含内存兜底以便测试）。
- **测试**：44 条单元测试（规则/符箓/流程/存档）。
- **合规**：全程无真钱/输赢/提现/抽卡/广告；内置健康与合规提示。
