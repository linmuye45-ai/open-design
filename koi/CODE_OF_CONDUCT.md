# 行为准则 Code of Conduct

本项目采用对贡献者友好、包容、尊重的社区准则（参考 Contributor Covenant 精神）。

## 我们的承诺

为营造开放包容的环境，我们承诺：无论年龄、体型、身心状况、族裔、性别认同与表达、经验水平、国籍、外貌、种族、宗教或性取向，参与本项目都是无骚扰的体验。

## 期望行为

- 使用友善、包容的语言。
- 尊重不同观点与经验。
- 优雅地接受建设性批评。
- 以社区整体利益为重。

## 不可接受的行为

- 骚扰、歧视、人身攻击。
- 发布他人隐私信息。
- 其他在职业场合被合理认定为不当的行为。

## 执行

如遇违规，请通过项目 Issue 或维护者邮箱报告，维护者将及时、公正地处理。
