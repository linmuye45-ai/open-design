# 锦鲤棋牌大全 · 合规与风控 (Compliance & Risk)

> 棋牌类产品的生命线是合规。本文件为产品/法务/运营的红线共识。

---

## 一、核心红线（绝不触碰）

1. **不涉赌**：游戏内**不得**存在任何形式的现金赌注、筹码与人民币的双向兑换、
   或变相的"赢钱提现"。所有虚拟货币/道具**只进不出**（不可兑换现金）。
2. **不诱导充值未成年人 / 不面向未成年人**：产品定位 30–65 岁，登录需实名，
   识别并拦截未成年账号。
3. **不设置概率误导**：抽奖/开箱类玩法（若有）须公示真实概率。
4. **不传播违法违规内容**：聊天/房间名/昵称须过滤敏感词。

## 二、资质与备案（上线前必备）

| 事项 | 说明 |
|---|---|
| ICP 备案 / 经营性 ICP 许可 | 网站/服务器备案 |
| 网络文化经营许可证 | 涉及网络游戏运营 |
| 软件著作权 | 客户端/服务端源码登记 |

| 等保测评 | 用户数据安全等级保护 |
| 实名认证接入 | 对接权威实名/防沉迷系统 |

> ⚠️ 具体资质以最新监管要求与专业法务意见为准，本文件不构成法律意见。

---

## 三、数据与隐私

- 遵循《个人信息保护法》《数据安全法》。
- 最小必要收集；明示隐私政策与用户协议。
- 敏感数据加密存储、传输 TLS；日志脱敏。
- 提供账号注销与数据删除通道。

---

## 四、反作弊与公平

- 服务端**权威校验**所有出牌（复用纯函数规则引擎），客户端不可信。
- 断线重连令牌防止顶号/伪造。
- 匹配 MMR + 风控识别外挂/协同作弊。
- AI 与真人区分标注，杜绝"暗中 AI 对局欺骗玩家"。

---

## 五、支付合规

- 走正规应用商店/微信/支付宝支付通道，明码标价。
- 未成年人充值拦截与退款机制。
- 保留完整交易凭证，配合监管审计。

---

## 六、风险登记册（Top Risks）

| 风险 | 影响 | 缓解 |
|---|---|---|
| 政策收紧（棋牌类监管） | 高 | 纯娱乐定位、提前储备资质、法务常态化 |
| 被误判为赌博 | 高 | 货币只进不出、无兑换、清晰用户协议 |
| 高并发稳定性 | 中 | Go 分布式架构、压测、灰度发布 |
| 获客成本过高 | 中 | 银发精准渠道、社交裂变、俱乐部联营 |
| 内容/聊天违规 | 中 | 敏感词过滤 + 人工审核 + 举报 |
| 数据泄露 | 高 | 加密、等保、权限最小化、审计 |
