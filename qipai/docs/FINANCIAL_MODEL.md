# 锦鲤棋牌大全 · 财务模型框架 (Financial Model)

> 本文件给出财务模型的**结构与关键假设**，具体数字需据实际渠道成本与留存数据填充。
> 建议用配套电子表格维护三张表：收入模型、成本模型、现金流。

---

## 一、关键假设变量（可调参数）

| 变量 | 符号 | 示例区间 | 说明 |
|---|---|---|---|
| 新增用户/月 | New | 依渠道 | 银发精准投放 |
| 次日留存 | R1 | 40–55% | AAA 体验驱动 |
| 30 日留存 | R30 | 12–20% | 多游戏交叉留存 |
| 付费率 | PayRate | 3–8% | 情绪价值/面子付费 |
| 付费用户 ARPPU/月 | ARPPU | ¥50–¥300 | 中老年高净值 |
| 获客成本 | CAC | 依渠道 | 需 < LTV/3 |
| 用户生命周期 | LT | 6–18 月 | 黏性玩法 |

---

## 二、收入模型

```
月活付费用户 = MAU × PayRate
月收入 = 月活付费用户 × ARPPU + 广告收入 + 赛事/联营分成
LTV = ARPPU × PayRate × LT   (简化，需按 cohort 精算)
```

**收入结构**（目标占比，随阶段演进）：
- 道具/装扮：50%
- 会员订阅：25%
- 赛事/俱乐部/联营：15%
- 适龄品牌广告：10%

---

## 三、成本模型

| 成本项 | 说明 |
|---|---|
| 研发 | 客户端/服务端/美术/音频/AI |
| 服务器与带宽 | 随并发规模，Go 架构降本 |
| 用户增长 | 投放 + 内容 + 裂变激励 |
| 运营与客服 | 银发用户重服务 |
| 合规与资质 | 备案/许可/等保/法务 |
| 支付通道费 | 商店/第三方抽成 |

---

## 四、单位经济（Unit Economics）健康线

- **LTV / CAC ≥ 3**：可规模化增长的核心门槛。
- **回收周期 < 6 个月**：现金流健康。
- **付费留存 > 免费留存**：验证付费心智真实。

---

## 五、融资与资金使用（本轮）

| 用途 | 占比 | 目的 |
|---|---|---|
| 研发 | 40% | 多游戏 + 并发 + 特效 |
| 用户增长 | 30% | 银发渠道精准获客 |
| 内容/赛事运营 | 20% | 留存与裂变 |
| 合规/团队 | 10% | 资质与人才 |

---

## 六、里程碑与资金节点

- **M1（种子里程碑）**：斗地主上线，验证 R1/R30/付费率 → 触发下一轮或加投。
- **M2**：多游戏"大全"，ARPU 提升 → 规模化投放。
- **M3**：百万并发 + 赛事 + 联营 → 正向现金流 / A 轮。

> 提示：所有数字须以真实 cohort 数据回填并按月滚动更新；本框架仅定义口径。
